# FinSight AI — Data Dictionary

## 1. Raw & Validated Transaction Schema

| Field Name | Type | Description | Constraints / Formats |
| :--- | :--- | :--- | :--- |
| `transaction_id` | String | Unique transaction reference ID | Required, primary key or unique |
| `account_id` | String | Unique account identifier | Required, foreign key to accounts |
| `timestamp` | Timestamp | ISO 8601 transaction date and time | Timezone-aware (default `Asia/Dhaka`) |
| `amount` | Float | Transaction nominal amount | Non-negative numeric (`amount > 0.0`) |
| `currency` | String | Currency ISO code | Supported: `BDT`, `USD`, `EUR`, `GBP` |
| `transaction_type` | Enum | Classification of money direction | `INCOME`, `EXPENSE`, `TRANSFER`, `REFUND`, `REVERSAL`, `PENDING` |
| `category` | Enum | Functional category | `SALARY`, `RENT`, `UTILITIES`, `GROCERIES`, `HEALTHCARE`, `DEBT_REPAYMENT`, `PAYROLL`, `SUPPLIER`, `TAX`, `DINING`, `ENTERTAINMENT`, `SHOPPING`, `INTERNAL_TRANSFER`, `UNCERTAIN` |
| `description` | String | Counterparty narrative or memo | Untrusted string; sanitized against injection |
| `counterparty` | String | Merchant or sender name | Optional |
| `is_internal_transfer` | Boolean | Intra-user account transfer flag | Flagged automatically to prevent spend inflation |
| `is_recurring` | Boolean | Flag for scheduled cadence | Detected via auto-correlation or metadata |
| `balance_after` | Float | Ledger ending balance after transaction | Optional in raw, validated in reconciliation |
| `is_essential` | Boolean | Protected non-discretionary obligation | True for Rent, Utilities, Debt, Tax, Healthcare, Payroll |
| `is_discretionary` | Boolean | Flexible discretionary spending | True for Dining, Entertainment, Shopping |

## 3. Risk Assessment & Prediction Schema

Generated by `src/finsight/ml_core/predict.py`:

| Field Name | Type | Description |
| :--- | :--- | :--- |
| `account_id` | String | Target account ID |
| `prediction_timestamp` | String | ISO 8601 prediction timestamp |
| `model_version` | String | Serialized model artifact semantic version (e.g., `1.0.0`) |
| `model_name` | String | Algorithm name (`random_forest`, `lightgbm`, etc.) |
| `raw_probability` | Float | Uncalibrated classifier posterior probability |
| `calibrated_probability` | Float | Post-calibration probability output in $[0, 1]$ |
| `decision_threshold` | Float | Cost-optimal threshold $\tau^*$ minimizing empirical expected loss |
| `is_shortfall_predicted` | Boolean | True if $\text{calibrated\_probability} \ge \tau^*$ |
| `risk_level` | String | Category: `LOW`, `MODERATE`, `HIGH`, `CRITICAL` |
| `expected_cost_of_action` | Float | Expected financial loss if intervention is triggered |
| `expected_cost_of_inaction` | Float | Expected financial loss if no action is taken |
| `explanation` | Object | Structured SHAP explanation payload |
